# Restaurant Consumption Analysis

## Overview
SQL Server project analyzing restaurant daily consumption data across multiple outlets.

## Key Analysis
- Most- and least-consumed items
- Outlet and category comparisons
- Daily, weekly, and monthly trends
- Data quality checks
- Optional cost and margin analysis when pricing data is available

## Tools
- Microsoft SQL Server
- T-SQL, CTEs, window functions, aggregations

## Note
The source data records consumption quantities, not confirmed sales. Revenue and profit analysis require reliable sales, price, and cost data.

## Files
- `restaurant_consumption_analysis.sql` — SQL analysis script
